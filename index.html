▸ Cómo leer esta página

La página tiene 3 niveles, de lo que tocás arriba hacia los datos crudos abajo:

  1. Acción → resultado. Eligís una estrategia (min-cost, balanced, max-quality, etc.) y abajo aparecen los 18 agentes con su modelo asignado + justificación.
  2. Datos de soporte. Tabla de fases SDD, scores BenchLM, pricing por request. Para entender por qué.
  3. Catálogo completo. Los 24 modelos activos con tier, score y precio. La fuente de verdad curada.

El badge de "datos del DD/MM" arriba te dice cuándo se actualizó el catálogo por última vez.

▸ Glosario de abreviaciones
arena
— LMArena ranking (ELO 0-∞).
swePro
— SWE-bench Pro score (0-100, agentic coding en repos reales).
sweVer
— SWE-bench Verified (0-100, subset curado por humanos).
term
— Terminal-Bench 2.1 (0-100, agentic shell).
BenchLM
— score compuesto 0-100 que pondera swePro/sweVer/term + reliability.
tier
— categoría de pricing: high flagship / balanced medio / budget económico / reference ancla.
lifecycle
— active (candidato a asignación) / reference (ancla de costo) / legacy (fuera de rotación).
minReasoning
— BenchLM mínimo que tiene que tener un modelo para ser asignado al rol (0-100).
costRatio
— fracción del costo del modelo reference que el rol está dispuesto a pagar (multiplicador).
soft fallback
— el modelo asignado NO cumple el minReasoning estricto pero es la mejor opción dentro del cost ceiling.
